\section{One question, two routes}
\label{sec:overview}

Suppose a benchmark pins a C program $p$ --- a loop over values read
from outside, an assertion inside --- and asks whether the assertion
can fail within twenty steps. In the system that sentence is formal.
C is a \emph{language}: a deterministic syntax plus a generated,
deterministic interpreter $I_C$ exposing named \emph{observables} ---
\code{bad}, whether an assertion failed, and \code{depth}, how many
statements have run --- and the certificate forms it can judge, each
with a generated checker. The \emph{question} is $p$, at C, with its
\emph{ask}: observable \code{bad}, mode \code{exists}, bound 20.

No search reasons about C directly; the model-checking searches live
at BTOR2, a language of bit-vector machines. A \emph{pair} connects
the two: one correspondence written as generated code, a translator
$T$ that turns the elaborated control flow of $p$ into a machine, one
statement one transition, and \emph{carry-backs} $\lam$ for whatever
must come home. Three kinds of artifact cross a pair, and each is
judged on arrival by an interpreter run. The program crosses forward
and is judged by \emph{the square} (\cref{fig:square}), closed for
every program of the pair's \emph{corpus} by running both
interpreters: $I_s(p) \equiv_\pi \lam(I_t(T(p)))$ on the kept
observables $\pi$. The horizontal arrows are untrusted syntax, the
vertical arrows are judges, and nothing horizontal is believed until
something vertical has run; a wrong translator loses squares and is
refused at the gate. The route ends at a \emph{search}, the one
partial transport, budgeted and allowed to return an honest
\emph{partial}. What it writes travels back and is judged where it
lands (\cref{fig:routes}): a \emph{witness} is carried home and
replayed by $I_C$, gap 0, \grade{certified}, and no generated code can
corrupt it, since a wrong search, carry-back, or translator all fail
the same way, by not producing an input that replays; a
\emph{certificate} is discharged by the checker of the language where
it lands, \grade{checked} at gap 1 if that is BTOR2, and
\grade{certified} once the pair carries it home to C's own checker; a
\emph{bare claim} is judged by nothing and floors at \grade{claimed}.

The same question also travels the longer route of \cref{fig:routes},
compiled to RISC-V --- a language whose interpreter is execution of
machine code --- then encoded to BTOR2. Pairs compose; a route's
forward contract is the componentwise meet of its hops', so a compiler
pair that keeps only \code{bad} makes the whole route a
\code{bad}-only route. What a second route can buy is a second
\emph{lineage}: results of disjoint generated descent that agree earn
the \emph{corroborated} flag --- not yet earned by these two, which
share one C front end. \Cref{sec:design} makes each word exact, \cref{sec:kernel}
says how the kernel is made trustworthy, \cref{sec:registry} lists
what was admitted, \cref{sec:frontier} says how the loop is run, and
\cref{sec:measurements} reports what fault injection and the plays
found.
